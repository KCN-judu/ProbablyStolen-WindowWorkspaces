[h1]Window Workspaces[/h1]
Windows snap into place while you drag them. Workspaces keep sets of open container windows, and one key switches between them.

[h2]What's new in 1.0.1[/h2]
[list]
[*]Leaving the store (back to the main menu, say) no longer keeps it in memory, so a later load in the same session does not start with the old store still loaded. Your workspaces are kept.
[/list]

[h2]Snapping[/h2]
[list]
[*]Dragged windows snap to the edges of other windows and of the screen. A guide line marks the edge they hold.
[*]Away from any edge they line up with a faint grid the size of one inventory cell.
[*]Hold [b]Alt[/b] to drag freely.
[/list]

[h2]Workspaces[/h2]
Like virtual desktops: each workspace is a set of open containers. Leave one and its windows are remembered and closed; enter another and its windows open where you left them, on the tab they showed.
[list]
[*][b]Next workspace[/b] key: switch to the next workspace, Shift for the previous one.
[*][b]Workspace manager[/b] key: create, rename, switch and delete workspaces, and take containers out of one. You can have up to nine. It is built like the game's own storage-preset manager.
[/list]
Workspaces are kept per save. A small notice shows which workspace you are in after each switch.

[h2]Performance and looks[/h2]
[list]
[*]Snapping does nothing while the mouse button is up, and a drag costs a few comparisons per frame.
[*]A switch opens windows over several frames, about 3 ms per frame, so the game keeps moving.
[*]The mod's windows, grid and guide lines use the game's own sprites, so texture packs restyle them.
[*]Works with Performance Fixes, which makes switching back to a workspace nearly instant.
[/list]

[h2]Setup[/h2]
Bind [b]Next workspace[/b] and [b]Workspace manager[/b] in the game's options menu. There are no default keys.

In-game text is available in every language the game supports. The mod needs no special permissions. Built for game version 0.46D.

[h1]窗口工作区[/h1]
拖动窗口时，窗口会自动吸附到位。工作区保存几组打开的容器窗口，一个键就能在它们之间切换。

[h2]1.0.1 新内容[/h2]
[list]
[*]离开商店（比如回到主菜单）后，模组不再把商店留在内存里，同一局里之后读档时，旧商店不会还占着内存。工作区照常保留。
[/list]

[h2]吸附[/h2]
[list]
[*]拖动窗口时，窗口会吸附到其他窗口和屏幕的边缘，并用一条参考线标出吸住的那条边。
[*]不靠近任何边缘时，窗口会对齐一层浅浅的网格，一格就是一个物品格子。
[*]按住 [b]Alt[/b] 可以自由拖动。
[/list]

[h2]工作区[/h2]
就像虚拟桌面：每个工作区是一组打开的容器。离开工作区时，模组记住它的窗口并关掉；进入另一个工作区时，那里的窗口会在原来的位置、原来的标签页重新打开。
[list]
[*][b]下一个工作区[/b]键：切换到下一个工作区，按住 Shift 再按则回到上一个。
[*][b]工作区管理[/b]键：新建、重命名、切换和删除工作区，也能把容器移出工作区。最多九个工作区。管理窗口照游戏自带的存储预设管理窗口搭建。
[/list]
工作区按存档分别保存。每次切换后，屏幕上会弹出一个小提示，显示你在哪个工作区。

[h2]性能和外观[/h2]
[list]
[*]松开鼠标键时，吸附什么都不做；拖动时每帧只做几次比较。
[*]切换时窗口分几帧打开，每帧约 3 毫秒，游戏不会卡住。
[*]模组的窗口、网格和参考线都用游戏自带的素材，材质包会改变它们的样子。
[*]可以和性能修复一起用，切回工作区几乎瞬间完成。
[/list]

[h2]设置[/h2]
在游戏选项里绑定 [b]下一个工作区[/b] 和 [b]工作区管理[/b] 两个键。这两个键默认没有绑定。

游戏内文字支持游戏的所有语言。模组不需要任何特殊权限。适用于游戏版本 0.46D。
